# 同初始张量：固定 kyy / 独立反演 kyy

用户批准两组同时运行，每组最多 60 次 L-BFGS-B 接受迭代。

| 区域 | 深度 [ft] | 初始 αxx | 初始 αyy |
|---|---|---:|---:|
| A | 14709.5–14712 | −18 | −18 |
| B | 14715–14717 | −17.5 | −17.5 |
| C | 14721–14727 | −19 | −19 |

- `fixed_yy`：反演三个 αxx；三个 αyy 固定在表中初值，**不固定为背景 −21**。
- `free_yy`：反演六个独立参数，顺序为 xx_A/B/C、yy_A/B/C；初始相等不表示后续强制各向同性。
- 背景 kxx=kyy=kzz=1e−21 m²；所有 kzz 固定。两个外部区的 kxx 保留 −15.5，其 kyy 保留背景 −21。
- 五个区的位置和宽度、观测裁剪、正半波变换、t=0 不计误差、压力源与力学参数保持原设置。
- 两组使用逐字相同的正演输入和观测：45×130 个求解采样点，129 步，240 步硬上限；原生数据仍为 45×3318。
- 两组各 20 MPI ranks、每 rank 1 线程；隐式 Euler、LU/MUMPS、三项容差 0.001，线性/非线性迭代上限 2000/200。
- L-BFGS-B：maxiter=60、ftol=1e−7、gtol=1e−8、maxls=20、所有自由参数界限 [−21,−12]。
- 每个自由的“区×方向”参数使用相同 smoothed L1：参考 −21、delta=0.05、beta=5.049311379654719e−15。固定 kyy 的常数惩罚不计入固定组目标；因此对照应比较数据误差与形态，不直接比较总目标。

## 最小实现扩展

原有 200 层 kxx reporter、映射和伴随梯度保留。仅新增三个 kyy reporter、三个 `ParsedOptimizationFunction`、互不重叠的分区 `FunctionAux`、三个伴随内积对象及 reporter transfers。
kyy 使用现有 `PorousFlowOptimizationAnisotropicDiffusionInnerProduct` 的 `component=1`；当前二进制的参数说明确认 `0=x, 1=y, 2=z`。无需改动或编译 C++。
C 区的 yy 梯度对象一次覆盖三个原有网格层，得到一个分区参数的梯度。

新 yy 梯度在初始点进行两方向中心差分（h=0.02），核对纯数据项，沿用原检查的 5% 相对 / 1e−7 缩放目标导数绝对门限。失败即停止六参数优化。已有 xx 有限差分不重复。

所有评估与接受迭代分开归档，并分别生成 xx、yy 渗透率 QC。求解失败中止该组，不返回伪造的零梯度；达到 60 次上限记录为用户迭代上限，提前收敛记录实际迭代数。两组结束后自动生成并排拟合图与结果摘要，不自动重启。
