# S 井 RFSDSS 与压力曲线相似性扫描

2026-09-20：扫描 56,507 个通道，深度 0.122–18861.023 ft，时间 0–384301.087267 s（3318 个原生时刻）。全部深度参与评分；主展示采用旧裂缝筛选脚本的 11500–16700 ft 范围。本次全井前列候选也都位于这个范围内。

这些数值描述曲线形状相似性，不是 MOOSE 拟合优度、因果证明或裂缝导流能力估计。最高几个相关系数差别很小，没有统计依据把微小排名差异视为显著差异。

旧脚本 `101_prototype_match.py` 明确选过 14888、14972、14992 ft。最接近这些整数深度的原生通道分别为 14887.970、14972.084、14992.111 ft，其相关系数为 0.97777、0.96261、0.88815。14888 附近最佳通道比整数最近通道偏约一个通道，不能混用这两个分数。14972 的上升明显较压力滞后，14992 的应变在压力回落前已有明显下降。

当前反演区的 B 中心 14716.403 ft 本身也与压力相似（r=0.98014），而 14711.065 ft 仅为 0.62425，14722.080 ft 为负相关 -0.70839。原区间拟合差不能简单归因于没有选到一个高相关通道；区间内各通道的响应差异、空间观测方式和物理模型仍需考虑。

## 方法与界限

1. 用现有 Fiberis/DSS2D 读取原始 S 井 RFSDSS；逐时间减去 7500 < MD < 15000 ft 的中位数。对 14710–14725 ft 子集逐项核对已有反演观测缓存，预处理和时间轴一致。
2. 使用当前模型压力源 `prod/gauges/pressure_g1.npz`，按绝对时间戳对齐，减去 DSS 起始压力，psi 转 MPa。目录标识为 prod；本分析不重新判定其现场井角色，也未替换成另一个名为 injection 的压力文件。
3. 排名采用每 1000 s 的均匀 QC 网格上的零滞后 Pearson 相关系数，避免原生不均匀采样时刻密度左右排名。这只是筛选网格，未改动任何求解时间表或反演观测。
4. 主排名采用有符号应变，并另存正半波相关系数。展示候选要求 p95-p05 动态幅度至少 0.5 微应变，代表点间隔至少 5 ft，以避免大量相邻通道占据同一个榜单。这两个值只是明确记录的 QC 筛选设置，不是仪器精度或地质尺度。
5. 曲线图展示原生应变；红色压力线仅做线性幅度缩放和常数偏移，**没有平移时间轴**。这些缩放只用于形状比较，不进入反演。
6. 上升段为 70–140 ks，后续上升段为 140–320 ks，回落段为 325 ks 以后。另在统一重叠时间范围内搜索 -20 至 +40 ks 滞后（步长 1 ks）；正值表示应变晚于压力。这是描述性检查，不能当作准确的水力传播时间；其相关系数与全时段零滞后系数使用不同支持区间，不能直接比较大小。
7. 历史 frac-hit 最近距离只作位置参照，没有直接把附近通道认定为同一条裂缝。相邻通道高度相关也不表示它们是统计独立的测量。
