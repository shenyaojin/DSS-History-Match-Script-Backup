# v6 敏感度网格 · 图怎么看（直白版）

## 这是在做什么

2 参数分区反演：**假定裂缝/SRV 区域位置已知**（从 DSS 读），只反演两个数——裂缝区的一个渗透率 `θ_frac` 和 SRV 区的一个渗透率 `θ_srv`。真值 `θ_frac=-14.52`、`θ_srv=-15.0`（都是 log10 渗透率，越准越好，误差单位 **dex = 差几个数量级**）。

我们扫了三个因子、各 3 档，共 **27 个反演**：
- **A = 真实 DSS 背景噪声**（从现场数据截的、含低频漂移）：bg1<bg2<bg3
- **B = 白噪声**（仪器噪声）：w1<w2<w3
- **C = 位置偏移**（区域绑错、模拟从 DSS 读错裂缝位置）：s0=不偏 / s2=偏 2 层(1 m) / s4=偏 4 层(2 m)

**一句话结论**：位置偏移是决定性的；噪声（不管真实 DSS 背景还是白噪声）影响都很小。下面每张图怎么看。

## 01_噪声设计_QC.png —— 先证明两种噪声确实不一样

只是交代"噪声是怎么造的"，6 个小图：
- **(a)** 一条道上，A（蓝，真实 DSS 纹理）是**平滑的低频漂移**，B（橙，白噪声）是**高频抖动**——一眼能看出俩不一样。
- **(b)(c)** A 的噪声场（横条纹=时间上相关）vs B 的噪声场（纯散斑）。
- **(e) 最关键**：功率谱。A（蓝）是"红噪声"——低频能量高、往高频掉 2 个量级；B（橙）**全平**（白噪声定义）。**这张证明因子 A 带了真实 DSS 的漂移结构，不是简单白噪声。**
- **(d)** 9 个数据集的总噪声大小（956→3814 nε）。**(f)** 最脏那格加噪后 vs 干净信号。

看这张只需知道：**A 和 B 是两种性质不同的噪声，都缩放到了可比的量级。**

## 02_敏感度热图.png —— 主结果，重点看这张

布局：**上排 = 裂缝渗透率误差 |θ_frac 误差|，下排 = SRV 渗透率误差 |θ_srv 误差|**；**三列 = 位置偏移 0 / 2 / 4 层**。
每个小方块图：**纵轴 = DSS 背景噪声档(bg1→bg3)，横轴 = 白噪声档(w1→w3)**，格子里的数字和颜色 = 误差(dex)，**越黑越差**。注意上下两排各有自己的色标。

**怎么读（三步）：**
1. **横着看上排三个图（左→右）**：shift=0 全是浅色（0.07~0.47）→ shift=2 变橙红（0.4~1.1）→ shift=4 **全黑（2.3~2.5）**。这就是位置偏移的威力：偏 4 层（2 m），裂缝渗透率就错 ~2.4 个数量级。
2. **在任意一个小方块内部看**（纵/横）：颜色几乎不变——说明**在固定几何下，背景噪声和白噪声怎么加都撼不动结果**（同一格内数字只差 0.1~0.3）。
3. **看下排（SRV）**：所有格子都很浅（≤0.31）——**SRV 那个参数对什么都稳。**

**结论**：位置偏移压倒一切；噪声几乎无所谓；SRV 参数最稳。

## 03_主效应.png —— 把上面的结论画成曲线

三个小图分别是"误差 vs 位置偏移 / vs 背景噪声 / vs 白噪声"，每张两条线（蓝=裂缝参数，橙=SRV 参数），是把其它两个因子平均掉后的趋势。

**怎么读**：只有**位置偏移那张的蓝线陡峭上冲**（0.24→0.73→2.40）；背景噪声、白噪声两张的线基本平（都在 1 附近微动——那 1 其实是把 s4 平均进来的底，本身趋势是平的）。橙线（SRV）三张都贴地。

**一眼结论**：**位置偏移是唯一显著的因子。**（细看：真实 DSS 背景噪声比白噪声略有一点上升趋势，但都远不及位置偏移。）

## 04~08 正演 QC 图 —— "反演出来的解，正演回去能不能重现观测"

这 5 张是**正演对比图**，每张 4 个面板：
- **左上 观测应变**：喂进反演的（带噪）观测。
- **右上 模拟应变**：用反演出的 θ 正演回去算的应变。
- **左下 残差 = 模拟 − 观测**（标题写了 max|res|）：**这是最该看的面板。**
- **右下 alpha 剖面**：反演结果（橙）vs 真值（蓝），纵轴是深度 y。

**核心看法（记住这条就够）：**
> **几何对齐时，残差是"噪声散斑"、幅值小；几何错位时，残差变大、而且在区带边界出现"相干的红蓝偶极带"。所以看残差的形态，就能判断裂缝位置有没有定错。**

逐张：

| 图 | 情况 | 残差 max | 残差长相 | alpha 剖面 |
|---|---|---|---|---|
| **04 最好** bg1_w1_s0 | 低噪+对齐 | 最小 | 纯噪声散斑 | 橙线几乎压住蓝线（近乎完美）|
| **05 中噪对齐** bg2_w2_s0 | 中噪+对齐 | 8.3e-6 | 噪声散斑、无结构 | 橙≈蓝，位置和量都对 |
| **06 偏2层** bg2_w2_s2 | 中噪+偏 2 层 | 居中 | 边界开始出现结构 | 橙块上移、略过冲 |
| **07 偏4层** bg2_w2_s4 | 中噪+偏 4 层 | 1.55e-5 | **明显红蓝偶极带**（结构化）| 橙块上移 2m + 大幅过冲到 −12 |
| **08 最差** bg3_w1_s4 | 高噪+偏 4 层 | 最大 | 结构化残差 | 偏得最离谱 |

**对比 05（对齐）和 07（偏4层）就是全部要点**：同样的噪声，只因为几何绑错了 2 m，残差从"干净噪声"变成"边界偶极带"、幅值翻倍，反演出的裂缝渗透率也从贴合真值变成过冲 2 个多数量级。

## 给导师的总结

1. **这个 2 参数分区策略对测量噪声很稳**：只要几何定对，真实 DSS 背景噪声和白噪声再大，裂缝渗透率误差也 <0.5 dex，SRV <0.25 dex。
2. **裂缝几何位置才是命门**：从 DSS 读错 2 m（4 层），裂缝渗透率就偏 ~2.4 dex，比噪声影响大一个数量级。**功夫要花在准确定位裂缝上，不是降噪。**
3. **好消息**：几何错位会在**正演残差里留下可识别的结构化图案**（区带边界偶极带），所以能用残差 QC 反过来检查/剔除定位错误。
4. 真实 DSS 背景噪声（带低频漂移）比同幅值白噪声影响略大，但两者都不是主要矛盾。
