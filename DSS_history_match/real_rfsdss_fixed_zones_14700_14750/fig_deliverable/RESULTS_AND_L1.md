## 当前目标函数

alpha_i = log10(k_i / m²)，背景 alpha_ref = -18。

Jdata = (1/2) sum_q (g(strain_sim,q) - g(strain_obs,q))²

R_L1 = beta * sum_(i=1)^200 [sqrt((alpha_i - alpha_ref)² + delta²) - delta]

J_optimizer = S * (Jdata + R_L1)

不整流组 g(s)=s；半波整流组 g(s)=max(s,0)。数据项是 L2 平方误差；“L1”指模型偏离背景的惩罚，不是残差的绝对值，也不是邻层差分的 TV 惩罚。

- alpha_ref = -18：惩罚偏离 k=1e-18m² 背景的幅度。
- delta = 0.05：平滑绝对值的转折尺度，单位为 log10 渗透率。让背景附近导数连续，并通过减 delta 使零偏差惩罚为 0。
- beta = 1.7423931907648512e-15：两组相同。
- S = 893333952.0：同时乘数据项和正则项，仅做数值缩放，不改变最优点。

beta 的实现：2e-11 × [sum(不整流实测应变²) / sum(v6 干净合成应变²)]，能量比约 8.7119659538e-5；原合成 beta 是 2e-11。该缩放是在本轮实测准备中设置的启发式选择，未经 L-curve、交叉验证或多 beta 扫描。整流组也使用不整流数据算出的同一个 beta 与 S。

五区共享到其内部层，背景固定。当前层数权重按候选区列表顺序是 [1,1,1,1,3]，所以正则项等价于 beta * sum_j n_j [sqrt((theta_j+18)²+0.05²)-0.05]。这是按层数求和，不按物理厚度积分，也不是五个参数等权。

最优点 R_L1 不整流为 1.7763949316e-14（数据项的 0.00335%）；半波整流为 2.9448680162e-14（0.00986%）。这轮正则权重很弱。

代码设置位置：prepare_runs.py 计算 beta_l1 和 objective_scale，写入两组 config.json；run_inversion.py evaluate() 使用它们，delta=.05、参考值=-18 在实现中固定。两组初值 [-15.5,-15.5,-15.5,-16.5,-16.5]，每区独立优化、范围 [-18,-12]，背景和区间位置、宽度固定。ftol=1e-7，gtol=1e-8，maxiter=60；两组都因目标函数相对下降达到阈值而收敛，并非梯度阈值触发。
